# Career gaps and career changes

**Gaps**
- Ask the candidate how they want to present it; never hide dates by fabricating.
- Short gaps (< 6 months) need no explanation. Longer gaps: one neutral line ("Career break — caring responsibilities, 2021–2022") optionally with anything relevant done (courses, freelance, volunteering).
- Using years only (2019–2021) is acceptable if applied consistently.

**Short tenures / contracts**
- Group contract roles under one "Independent consultant / Contract roles" entry with client bullets.
- Mark contracts explicitly ("Contract") so short tenures read as intended.

**Career changers**
- Lead with a summary that names the target role and the transferable strengths.
- Add a "Relevant experience" or "Selected achievements" section that surfaces transferable evidence first.
- Translate old-domain jargon into the new domain's language.
- Put relevant training, certifications and projects prominently.
