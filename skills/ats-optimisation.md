# ATS-friendly formatting

- Use standard section headings: Profile/Summary, Experience, Skills, Education, Certifications, Projects.
- Keep core content in a single column of real text. Avoid putting essential information in images, icons, text boxes, headers/footers or tables.
- Job title, employer and dates should be clearly associated in each entry; use one consistent date format.
- Use common fonts and normal bullet characters.
- Spell out acronyms once when the listing does ("Search Engine Optimisation (SEO)").
- Mirror exact job-title and skill keywords where truthful; ATS matching is often literal.
- File name and PDF: text must be selectable (not a scanned image). The app's PDF export keeps text selectable.
- Avoid skill "rating bars" or percentages — they parse badly and invite scepticism.
